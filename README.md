# Throw a Ball

**Throw A Way Games presents Throw a Ball**

## Roller Ball prototype v0.12

This focused playtest is a single-player, 128×128 Roller Ball board with a
64×32 setup display.

- **Arcade:** choose Arcade, throw one physical dart, watch the virtual ball
  travel to its destination, score, then remove the dart for the next ball.
- **Pro:** choose one of three Aim positions with Left/Right, lock with A, mash
  A during the Power window, then throw one scoring dart at Throw Ready.
- Yellow, Green, and Red are broad power zones. Red is not inherently best:
  power, Aim, and dart placement are combined with automatic path correction.
- B moves backward through Machine, Play, Aim, Power, and Throw Ready without
  spending a ball.
- A used dart remains blocked until removal, so it cannot trigger another ball.

The game uses nine balls and the existing 10 / 20 / 30 / 40 / 50 / dual-100
Roller Ball target layout. This remains a procedural mechanics prototype.
